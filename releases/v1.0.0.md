# Invis v1.0.0

First public downloadable release of the Invis meeting workspace.

## Downloads

- `Invis-1.0.0-mac-arm64.dmg`: installer disk image for Apple Silicon Macs running macOS 13 or newer.
- `Invis-1.0.0-mac-arm64.zip`: the same application as a ZIP archive.
- `SHA256SUMS.txt`: SHA-256 checksums for both downloads.

No Node.js installation is required. Open the DMG, drag Invis to Applications, and launch it. The app starts hidden: press **Command+B**, then use the workspace icon to open your library. Configure your own Gemini API key in Settings for transcription and AI features, or turn off live transcription to record locally.

## Included

- Local meeting library, microphone and meeting audio recording, and WAV playback/export.
- Live transcription, transcript imports, meeting analysis, Ask AI, and dictation polish.
- Floating controls, transparency settings, and user-supplied prompts.
- No bundled personal documents, API keys, custom local prompts, or private invisibility modules.

## Verification and limits

The source test suite and syntax checks pass, including CI on macOS, Windows, and Linux. The macOS ARM64 application was packaged locally. Platform CI does not verify physical microphones, meeting audio capture, or live provider access.

This build is **unsigned and not notarized**. macOS may block it or require explicit approval. Windows, Linux, and Intel Mac installers are not provided in this release. System audio depends on OS permissions and capture support. Screen-capture protection is not a guarantee of invisibility.

AI features send selected audio or meeting context to Gemini and may incur provider charges. An API key is not included. The default application excludes the legacy overlay; its known limitations are documented in SECURITY.md.

To check a download on macOS, place both archives and SHA256SUMS.txt in the same folder and run `shasum -a 256 -c SHA256SUMS.txt` there. These checksums verify integrity, not publisher identity or code signing.
